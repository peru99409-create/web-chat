はじめに

この利用規約（以下「本規約」）は、「ウェブチャット」（以下「本サービス」）の使い方のルールと、データの取り扱いを定めるものです。本サービスを使う人（以下「利用者」）は、本規約に同意したうえで利用してください。

本サービスを作って配布している人を「運営者」といいます。

このページは、本サービスの実際のしくみに合わせて書いています。長いので、上の見出しから読みたいところへ移れます。

第1条（本サービスについて）

  1. 本サービスは、登録なしで、同じ部屋名を知っている人どうしが、文字でやり取りできるチャットです。
  2. 会員登録やログインはなく、運営者が会員情報を管理するしくみもありません。
  3. メッセージの送受信は、第三者が公開している通知配信サービス（ntfy.sh）を経由します。運営者の専用サーバーではありません。
  4. 本規約の「部屋」「ID」「表示名」「伝言板」は、本サービスの画面にある同じ名前の機能を指します。
  5. 本サービスは無料で提供します。

第2条（規約への同意と変更）

  1. 本規約は、利用者と運営者との間の契約の内容になります。不特定多数の利用者に同じ内容で提供するため、民法の「定型約款」として扱います。
  2. 本規約は、入口・ホーム画面・設定から、いつでも読めます。利用者が、本規約を確認できる状態で、「同意して入る」を押したとき、または本サービスを利用したときは、本規約に同意したものとみなします。
  3. 初めて部屋に入るとき、同意の確認を表示します。使い方の練習の部屋は、同意の前でも体験できます。練習の内容は、外には送られません。
  4. 運営者は、変更が利用者の一般の利益に合うとき、または、契約の目的に反せず、変更の必要性や内容などからみて合理的なときは、本規約を変えることがあります。
  5. 変更するときは、効力が生じる日を決め、その前に、お知らせまたはこのページで、変更することと変更後の内容をお伝えします。大きな変更のときは、もう一度同意を確認します。
  6. 効力が生じる日のあとも使い続けた場合は、変更後の規約に同意したものとみなします。
  7. 本規約のうち、利用者の利益を一方的に害し、信義誠実の原則に反する条項は、同意したものとはみなしません。
  8. 同意できない場合は、利用をやめてください。同意の記録は、このページの下から取り消せます。

第3条（利用できる人と費用）

  1. 利用者は、自分の責任で本サービスを利用します。
  2. 未成年の方は、保護者の理解と同意を得てから利用してください。13歳未満の方は、保護者と一緒に使ってください。
  3. 端末、インターネット接続、通信料、電源は、利用者が用意し、負担します。
  4. 最新の主要なブラウザ（Chrome・Safari・Edge・Firefox）での利用を想定しています。古い環境では、一部の機能が動かなかったり、暗号化が働かなかったりすることがあります。

第4条（IDと表示名）

  1. IDは、利用者が入れた文字から自動で作られる6文字の記号です。同じ文字を入れれば、いつでも同じIDになります。
  2. 入れた文字そのものは、他の利用者には送られません。ただし、同じ文字を知っている人は、同じIDを名乗れます。IDのもとにした文字は、パスワードのように秘密にしてください。
  3. 会員登録がないため、運営者がIDや設定を復元することはできません。端末のデータを消すと、設定や登録は戻りません。同じ文字を入れれば、同じIDには戻れます。
  4. 違う文字から同じIDができる可能性は、ゼロではありません。IDは、本人であることの証明ではありません。
  5. 表示名は自由に付けられます（12文字まで）。同じ表示名を別の人が名乗ることもできます。
  6. 他の人、運営者、公的機関、企業になりすます表示名やIDは使えません。
  7. 「✓」「✕」は、利用者が自分の端末に登録した名前とIDを照らし合わせた目印です。本人であることや、安全であることを保証するものではありません。
  8. IDを作らずに入った場合は、仮のIDになります。部屋を出ると消えます。

第5条（部屋と鍵）

  1. 部屋は、部屋名で決まります。大文字・小文字、全角・半角、余分な空白の違いは区別しません。
  2. 部屋名を知っている人は、誰でも同じ部屋に入って、読み書きできます。入室の承認、管理者、パスワードの機能はありません。
  3. メッセージを暗号化する鍵は、部屋名から作られます。部屋名は「合言葉」です。短い名前、よくある名前、推測しやすい名前は、知らない人が偶然または意図的に入ってくることがあります。
  4. 見られたくない会話には、長くて推測されにくい部屋名を使い、部屋名やリンクは信頼できる人にだけ伝えてください。
  5. 部屋に入る・出ることは、同じ部屋の人に伝わります。
  6. 自分の通信が切れた状態が30秒ほど続くと、自動で退室します。放置しているだけでは、退室になりません。
  7. 同時に入れる部屋は3つまでです。画面の下のバーで切り替えます。戻るボタンを押すと、横からホームが半分だけ出ます。部屋には入ったままです。退室するには、いまの部屋のボタンから「この部屋から退室する」を押すか、ホームの「退室」を押してください。入ったままの間は、その部屋の人に在室として見え、通知も届きます。
  8. IDを変えると、入っているすべての部屋から退室します。
  9. 「公式」という名前の部屋は、公式部屋です。ホームの先頭に表示されます。公式部屋では、第7条の強めの制限が適用されます。運営者が常駐したり、投稿を確認したりするとは限りません。

第7条（荒らし対策と制限）

安心して使えるように、次の制限と自動の対策があります。数字は変わることがあります。

  • チャット：1.5秒に1回まで。1通は500文字・10行まで。リンクは2つまで。同じ内容は30秒以内に続けて送れません。同じ部屋で15秒間に8通以上を続けて送ると、いったん止められます（少し待つと、また送れます）。この数え方は部屋ごとで、ほかの部屋で送った分は数えません。
  • 伝言板：1回100文字・3行まで。10秒に1回まで。リンクは2つまで。1人が残せるのは3件まで、部屋全体で40件まで（古いものから消えます）。同じ伝言は5分以内に続けて書けません。
  • 表示名の変更は10秒に1回、アイコンの変更は15秒に1回、部屋の出入りは2秒に1回までです。
  • リアクションは、3秒に1回ほどまで（公式部屋では8秒に1回ほど）です。返信は、チャットと同じ制限です。
  • 受け取る側でも、見えない文字や長いくり返しの除去、短い時間に多すぎる投稿の無視を行います。連投する人は、一時的に非表示になります（5分、くり返すと15分、1時間。この画面を開いている間だけ）。
  • 公式部屋（official）では、さらに強めの制限があります：チャットは5秒に1回・200文字・5行まで、リンクは使えません。30秒に3通以上送ると60秒間送れなくなります。同じ内容は2分以内に続けて送れません。伝言板は30秒に1回・60文字・2行まで、リンク不可、1人1件、部屋全体で20件までです。
  • 公式部屋では、受け取る側の制限も強めです。連投する人は、15分、くり返すと1時間、さらに6時間、一時的に非表示になります（この画面を開いている間だけ）。「公式」「運営」「管理」「official」「admin」などを含む表示名は、なりすまし防止のため、IDだけの表示になります。
  • 外部リンクは、開く前に確認が出ます。
  • ミュートを使うと、その人の発言が自分の画面だけに出なくなります。

自動の対策は、ふつうの使い方でも、まれに投稿が止まったり、一時的に非表示になったりすることがあります。そのときは、少し待ってください。

対策は完全ではありません。入ってほしくない人の入室を止める機能はありません。迷惑な人には、ミュートで対応してください。

  4. 他の利用者の投稿やアイコンを、本人の同意なく、コピー・転載・公開・販売してはいけません（個人で使う範囲を除きます）。

第9条（送られる情報と、見える人）

本サービスは、次の情報を中継サービスへ送ります。

  • メッセージの本文・時刻・吹き出しの色や右左の設定・吹き出しの背景の値（1000文字まで）・ささやきの相手・返信の元の文（40文字まで）・リアクション：暗号化して送ります。
  • ID・表示名：暗号化されません。中継のための封筒に書かれて、そのまま送られます。
  • 入室・退室・在室の合図（1分おき）と、いま部屋にいる人の一覧：同じ部屋の人に届きます。
  • アイコン：小さな画像（最大96px四方）は暗号化して送ります。大きな画像（最大512px四方）は、暗号化した添付として、短い時間だけ預けます。
  • 伝言板の書き込みと削除の合図：暗号化して送ります。

部屋名そのものは送りません。部屋名から作った識別用の記号だけが、中継サービスに見えます。

IPアドレスやブラウザの種類などの通信情報は、通信するだけで、中継サービス（ntfy.sh）に届きます。その扱いは、同サービスのルールによります。

本ページには、広告や、利用者の行動を追いかけるためのしくみは入れていません。運営者が、利用者のメッセージや個人情報を集めて分析することはありません。

IDと表示名は暗号化されません。本名や、個人が特定できる名前を、表示名にしないでください。

第10条（暗号化について）

  1. 本文は、部屋名から作った鍵で暗号化（AES-GCM）されて送られます。
  2. 部屋名を知っている人は、鍵も作れるので、全員が読めます。部屋名を知らない人や、中継サービスが読むのは難しいですが、部屋名が推測しやすい場合は、総当たりなどで読まれるおそれがあります。
  3. 「絶対に読まれない」ことは、保証できません。
  4. ブラウザが暗号の機能を使えない環境（安全でない接続の古い環境など）では、暗号化されず、文字を変換しただけの状態で送られます。画面の上に「暗号化」と出ているか、確かめてください。
  5. 相手の端末や画面を見られること、スクリーンショットを撮られることは、防げません。
  6. IDや表示名、入退室の情報は暗号化されないので、中継サービスの内容を見られる人には分かります。

第11条（保管と削除）

  1. 中継サービスは、メッセージを一定の時間（12時間ほど）預かり、あとから入った人にも渡すことがあります。期間は、中継サービスの運用で変わります。
  2. 運営者は、中継サービスに預けられた内容を、ひとつずつ消すことができません。伝言板の自分の書き込みは、自分で削除できます。ただし、すでに読まれたものや、しくみ上すぐには消えないものがあります。
  3. 部屋のメッセージは、画面に最大30件までです。部屋を出る、またはページを閉じると、端末には履歴が残りません。
  4. 大きなアイコンの預かりは、数時間で自動的に消えます。
  5. 他の利用者の端末に届いた内容は、その人の端末に残ることがあります（スクリーンショットなど）。運営者には消せません。

第12条（端末に保存される情報）

このブラウザの中（localStorage・IndexedDB）に、次の情報が保存されます。

  • IDのもとにした文字、表示名
  • 最近入った部屋の名前（最大6件）
  • 通知・音の設定（登録した人だけ・位置・止める時間帯を含む）、部屋名を伏せる設定、部屋ごとの見た目、吹き出しの色・位置・吹き出しのCSS
  • 自分のアイコン（小さい画像と大きい画像）、他の人の小さなアイコンのコピー（最大80件）
  • お友達の登録（自分用のあだ名を含む）、ミュートした人
  • 荒らし対策のための、直近の送信時刻や内容の記録
  • お知らせ・使い方・規約を確認した印

これらは、運営者には送られません。相手に届くのは、第9条に書いた情報です。

IDのもとにした文字は、端末に残ります。共用の端末では、使い終わったら、ブラウザのデータを消してください。

ブラウザのデータを消したときや、プライベートブラウズを閉じたときは、これらは消えます。
